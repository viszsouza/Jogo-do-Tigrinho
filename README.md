<h2 align="center">🎮 Regras & Mecânica 🎮</h2>

<div align="center">

| Ação | Detalhe |
| :--- | :--- |
| 🎯 **Objetivo** | Descobrir o número secreto sorteado entre **1 e 100** |
| 💵 **Saldo Inicial** | `R$ 1.000,00` em moedas fictícias |
| 🎟️ **Custo do Giro** | `R$ 50,00` por tentativa |
| 🏆 **Prêmio (Big Win)** | `R$ 500,00` ao acertar o número |
| 🔄 **Bônus** | Recarga gratuita de `R$ 1.000,00` caso o saldo zere |
